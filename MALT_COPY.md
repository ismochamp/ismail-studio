# Malt portfolio copy

## Title
A WordPress Service Website with a Working Inquiry Desk

## Short description
A service website needs to do more than explain capabilities. A visitor’s inquiry must reach a usable staff record, with clear validation, truthful confirmation and a manageable follow-up process. This independent project connects the public website to that complete local workflow.

## Project description
Built an original responsive WordPress theme and custom inquiry plugin for Ismail Habib’s services. The website guides visitors through AI automation, API integration, web development and legacy modernization. Validated forms store inquiries in the WordPress database. Authorized administrators can review records, mark them reviewed, export CSV and delete them. The package includes editable pages, source code, installable theme and plugin ZIPs, a repeatable local Docker setup and a separate Python/SQLite runtime.

Executed in real WordPress 7.1.2 using official container images. All 8 WordPress integration checks passed, including form protection, saved inquiry, authenticated inbox, review state, CSV export and deletion. The separate Python runtime passed 4 integration tests for pages, validation, persistence, escaping and the staff workflow. Tests used labeled synthetic input and removed it afterward.

**Project status:** New independent project created for my own portfolio. The WordPress implementation is functional and verified locally. It is not presented as a past paid client project or a public production deployment.

## What I delivered
- Responsive custom WordPress theme and service pages
- Validated inquiry form with local database persistence
- Authenticated staff inbox, review status, CSV export and deletion
- Installable packages plus a lightweight Python/SQLite runtime
